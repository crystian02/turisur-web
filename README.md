# Turisur Web

Panel administrativo para Buses Turisur.

Repositorio de solo lectura con fines de referencia técnica. Las
credenciales y variables de entorno no están incluidas.

## Módulos

- Monitoreo GPS en vivo con Google Maps y Socket.io
- Gestión de horarios, rutas y tarifas
- Auditoría de pagos Webpay Plus
- Reportes de recaudación con Chart.js
- Buzón de consultas, reclamos y objetos perdidos

## Stack

Next.js 14 · React · Tailwind CSS · Supabase · Google Maps · Socket.io · Chart.js

## Notas

Proyecto privado de Buses Turisur.
